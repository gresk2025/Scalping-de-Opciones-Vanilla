⚙️ Configuración de Binance Opciones

Ingresa tus claves de API cuando decidas operar en Modo Real. El sistema probará la conexión y los permisos de opciones antes de guardar.

  1. Entra a tu cuenta en Binance: Inicia sesión normalmente.
  2. Gestión de API: Haz clic en el ícono de tu perfil (arriba a la derecha) ➔ Gestión de API (API Management).
  3. Crear API: Clic en el botón amarillo Crear API ➔ Selecciona la opción Generada por el sistema (HMAC).
  4. Nombre descriptivo: Asígnale un nombre (por ejemplo: Bot-Opciones-Solana).
  5. Verificación de Seguridad: Completa tu verificación (código por correo / 2FA / Passkey).
  6. Restricción de IP (REQUERIDO para Opciones):
    Haz clic en "Editar restricciones". Selecciona "Restringir el acceso solo a IPs de confianza" e introduce la IP de tu servidor VPS:
    IP_DE_TU_VPS
    Al colocar tu IP fija, Binance desbloquea el trading de opciones y evita que la clave expire cada 90 días.
  7. Permisos a Activar:
    • ✅ Habilitar Lectura (Enable Reading).
    • ✅ Habilitar Opciones / Trading de Opciones Vanilla (Enable Vanilla Options Trading).
    • ⛔ NUNCA marques "Habilitar Retiros" (Withdrawals). El dinero jamás podrá salir de tu cuenta; el bot solo compra/vende opciones.
  8. Copia del Secret Key:
    ⚠️ Copia tu API Key y tu Secret Key inmediatamente. Binance solo muestra el Secret Key una sola vez al crear la API; si recargas la página se ocultará para siempre.
  9. Billetera de Opciones:
    En Binance, transfiere tu saldo de trading ($10 a $30 USD) a la Billetera de Opciones (Options Wallet) desde Billeteras ➔ Transferir ➔ De Spot a Opciones (es instantáneo y sin comisiones).
